# Репозиторий F-Droid

Адрес после включения GitHub Pages и первого успешного запуска:

https://okedokii.github.io/firefox-ruca-android/fdroid/repo/

В F-Droid откройте настройки репозиториев, добавьте этот адрес и сверьте
SHA-256 сертификата:

`EC29A528497EBBF0CEF55CF413658E0476EE2294FECC367092D2DD12224ED8EA`

Этот отпечаток относится к сертификату индекса, а не к контрольной сумме APK.
Страница GitHub Pages и сводка Actions также содержат ссылку с отпечатком.

## Однократная настройка

1. Откройте Settings → Pages → Build and deployment → Source → **GitHub Actions**.
2. Убедитесь, что уже настроены `RUCA_KEYSTORE_B64` и `RUCA_KEYSTORE_PASSWORD`.
3. В Actions запустите **Publish F-Droid repository** через **Run workflow**.

Если публикацию блокирует правило окружения `github-pages`, разрешите деплой
из `main` в настройках этого окружения.

Новые ключи не генерируются. Индекс подписывается тем же постоянным ключом,
которым подписывается приложение; сертификат проверяется по
`ci/signing-identity.json`. Это сознательное упрощение: отдельный ключ индекса
потребовал бы дополнительных Secrets. Не заменяйте его без плана миграции
клиентов. Закрытый ключ и конфигурация с паролями находятся только во временном
каталоге runner и удаляются. Pages получает исключительно публичный каталог.

## Обновления

Workflow запускается при публикации, редактировании или удалении релиза,
после успешного завершения workflow «Цифролис» и «Publish tested release»,
при изменении конфигурации F-Droid в `main`, а также вручную.
Запуск после сборочного workflow нужен потому, что релизы, созданные через
`GITHUB_TOKEN`, сами по себе не вызывают событие запуска другого workflow.

Из двадцати последних подходящих стабильных опубликованных релизов выбираются
три APK с наибольшим фактическим `versionCode`. Черновики и предварительные
релизы исключаются. APK прежних пакетов пропускаются. У APK пакета
`io.github.okedokii.cifrolis` проверяются подпись постоянным ключом и SHA-256
по файлу релиза; при наличии также проверяется digest GitHub.
Ошибка проверки останавливает публикацию и сохраняет прежний сайт.

В каталог попадают исходные подписанные APK без переподписывания.
При следующем релизе увеличивайте `versionCode`, сохраняя пакет и ключ.
APK из GitHub Releases и F-Droid могут обновлять друг друга.
Сборки прежнего пакета устанавливаются отдельно; данные между разными пакетами
автоматически не переносятся.

Если подходящего APK пока нет, публикуется подписанный пустой репозиторий.
Приложение появится после первого стабильного релиза с новым пакетом.
Удалённые или переведённые в prerelease релизы исключаются при следующем запуске.
Все старые GitHub Releases сохраняются; ограничение в три версии относится
только к Pages. Размер сайта ограничен скриптом до 900 МиБ.
